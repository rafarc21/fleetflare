### S44-F1. fleet-cockpit's deploy-gate sentence cites `scripts/deploy.sh` — the path does not exist at repo root — GLM-OK

- **Site:** skills/fleet-cockpit/SKILL.md:470 — "**`bun run deploy` runs `fleet rescue-all` itself** (issue #251; gate built into `scripts/deploy.sh` by issue #20)".
- **Reality:** the script lives at `apps/fleet/scripts/deploy.sh`; `bun run deploy` resolves it via apps/fleet/package.json's `"deploy": "scripts/deploy.sh"` run from apps/fleet. No `scripts/deploy.sh` exists at repo root (verified: `ls scripts/` in fleetflare root shows only junior-eval, public-export.sh, test). A reader who goes hunting for the gate from repo root finds nothing; docs/setup.md:310 and operations.md cite the same script with the `apps/fleet/` prefix or `scripts/deploy.sh` from apps-fleet-relative context.
- **Proposed fix:** fleet-cockpit/SKILL.md:470 — change "`scripts/deploy.sh`" to "`apps/fleet/scripts/deploy.sh`" (one path fix; every other citation of this script in the repo carries the prefix).
