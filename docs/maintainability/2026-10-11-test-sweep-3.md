## Method

The brief's four categories: duplicated fixture builders (same fake
storage/deps literal 3+ times), tests asserting implementation detail
instead of interface behavior, giant test files (>1500 lines) worth
splitting by behavior, dead helpers / skipped tests with no reason /
stale issue-number comments narrating history. Findings by grep census
+ reading the files; line refs at `origin/main` 360570b.
