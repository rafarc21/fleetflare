Refs #850 (sweep 43, F14; census doc docs/maintainability/2026-10-14-dup-fixtures-sweep-43.md, merged as #896). Test-helper-only change, no behavior change, no app code.

Finding (S43-F14): apps/fleet/test/studio.stopped-stays-stopped.test.ts:34 and apps/fleet/test/studio.wake-gate.test.ts:34 carry a byte-identical 4-line wrapper:

    function fakeStorage(seed?: StudioStatus) {
      const s = doStorage(seed ? { [STATUS_KEY]: seed } : undefined);
      return s as unknown as StudioStorage & { map: Map<string, unknown> };
    }

Both wrap helpers/do-storage.ts's fakeStorage: seed { [STATUS_KEY]: seed }, cast StudioStorage & { map }. This is the exact wrapper pattern sweep 18 F10 cited wake-gate:34 as the model for; the pair is new ground at sweep 43's 2+ bar. Subjects: stopped-state transition + wake gate — no lane member.

## Change

helpers/do-storage.ts exports statusStorage(seed?: StudioStatus) beside fakeStorage:

    export function statusStorage(seed?: StudioStatus) {
      return fakeStorage(seed ? { [STATUS_KEY]: seed } : undefined)
        as unknown as StudioStorage & { map: Map<string, unknown> };
    }

The helper gains imports from src (STATUS_KEY, StudioStorage from ../src/studio/provision via the test-relative path ../../src/studio/provision; StudioStatus from ../../src/studio/types) — first src imports in this helper, same precedent do-storage.test.ts:7 already set. The cast lives once in the helper; call sites get the typed shape directly. Both suites import statusStorage and delete their local wrappers, renaming call sites fakeStorage(...) → statusStorage(...). do-storage.ts's header comment gains one line noting statusStorage's purpose (seed StudioStatus under STATUS_KEY; sweep-43 F14).
