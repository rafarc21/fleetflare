# Plan — local studio = studio: `ff --local` / `fleet spawn --local` (#1248)

## Objective

A local studio is a studio that runs on the operator's Mac; only WHERE differs. `--local` on `fleet spawn` and `ff` creates an Orca worktree from a local clone, launches the lead with the SAME blueprint role prompt + house rules + lead-never-implements hook the container uses, and registers it in the Worker registry with `host: "local"` so `fleet ls` shows it and `fleet task assign`/envelope/done-record work identically. `fleet destroy` on a local studio tears down by PATH (never `name:`).

## Design decisions

1. **Schema** (`src/studio/types.ts`): `StudioStatus.host?: "local"` (absent = cloud, byte-compat with every existing row) and `StudioStatus.localPath?: string | null` (the Mac-side absolute path to the local clone). `ProvisionConfig` gains `host?: "local"` and `localPath?: string`.
2. **Shared id allocation** (`src/studio/spawn.ts`): `runSpawn` is reused UNCHANGED for the decision/claim/brief half. New `readLocalRequest(body)` reads `{ local: true, localPath }`; the claim placeholder and `provisionChild` config carry `host`/`localPath`. `liveStudioCount` excludes `host === "local"` rows — local studios are not containers and must never count toward `DEFAULT_MAX_STUDIOS`.
3. **Registry route** (`src/studio/routes.ts` + new `src/studio/local-spawn.ts`): `POST /studio/local/spawn` (Access-gated, beside `/studio/spawn`), parent = operator, `resolveWorkRepo` still verifies the repo. `spawnDeps` wired with `provisionChild = registerLocalStudio` (writes D1 row `running, host:"local", localPath` via `recordStudio`, NO DO/container) and `notifyMaestro = noop` (the sweep supervises containers only). After `runSpawn`, resolve the bring-up env via `resolveBringupEnv` over the real ProvisionDeps and attach decoded `prompt`, `allowedTools`, `effort`, `members` (decoded map), `skills`, `leadType` to the response. NOTE the one wiring risk: a standalone Env→ProvisionDeps builder (do.ts's `deps()`/`refreshDeps()` is DO-scoped); if none exists, build the minimal set (fetchBlueprintFile, memoryRepo, opsRepo, juniorEnabled, resolveAssignedBrief) from env.
4. **Destroy-by-path** (`src/studio/routes.ts`, `cli/fleet.ts`): `fleet destroy` on a local row must NOT RPC the container DO. routes' `destroy` branch short-circuits to a D1 row flip to `stopped` (host stays local) + the existing `closeStudioRow` Orca teardown, which already removes by PATH. `cmdDestroy`'s teardown (already `closeStudioRow`) is unchanged.
5. **CLI** (`src/studio/cli-args.ts`, `cli/fleet.ts`, `cli/ff.ts`, `cli/orca-workspace.ts`): `fleet spawn <role> --local [--path <abs>]` and `ff <role> --local`. `localPath` defaults to `git rev-parse --show-toplevel`. `cmdLocalSpawn`: detect repo, POST `/studio/local/spawn`, then `ensureLocalStudioWorktree(id, localPath, defaultBranch, deps)` (new, runs `orca worktree create --repo "path:<localPath>" --base-branch "origin/<default>" --agent claude --name studio-<id> --no-parent --setup skip`), then materialize the lead PROJECT-SCOPED (never global `~/.claude`, respecting #20's cancellation): write `<worktree>/.fleet/working-set.md` (prompt), `.claude/agents/*.md` (members), `.claude/skills` symlinks, and `.claude/settings.json` (project-scoped PreToolUse lead-gate hook from the local checkout's `gates/lead-gate.sh`, fail-closed `exit 2`, matcher `.*`, copied to `.claude/hooks/`). Launch via `orca terminal create --command "claude --append-system-prompt <prompt> --allowedTools <allowedTools> [--effort <effort>]"` in the worktree, then rename the terminal to `<id>`. `ff --local` short-circuits `ffDecision` to a local spawn (same `nextFreeInstance` allocation).
6. **HOST column** (`cli/fleet.ts` `formatTable`, `src/studio/grid.ts`): render `local` for `host === "local"` rows, else `tailscaleHost ?? "-"`.
