# GLM-OK 3021 same-model backoff (refs #767)

Problem: GLM account 20 rpm; ~60% of lead calls get `3021: rate limiting`; anthropic-route.ts 429s at once; Claude Code exhausts its retry budget and ends the turn; studio idles.

Approach: new `runAiWithRateLimitBackoff` wraps `runAiWithRetry` — on a rate-limited (isRateLimited) exhaustion, sleep per schedule [3s,6s,12s,20s], jitter ±30% (`ms * (0.7 + 0.6 * random())`), rerun same model, max 4 extra rounds, total sleep capped 45s. `runModelPoolOverflow` applies the wrapper ONLY when `order.length === 1` or every OTHER candidate already 3021'd once this walk (a Set of model ids); otherwise keeps today's move-to-next-model-first. Exhausted → unchanged 429 rate_limit_error + retry-after 30. `attempts` accumulates every ai.run call across rounds.

Files: apps/fleet/src/llm/anthropic-route.ts, apps/fleet/test/llm.anthropic-route.test.ts.
