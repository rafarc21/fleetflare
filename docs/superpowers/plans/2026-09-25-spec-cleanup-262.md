# Spec cleanup — dead-numbers contradiction + wrong doc pointer (board issue #262)

Docs-only, no behavior change.

## What was wrong

1. `docs/superpowers/specs/2026-09-24-row-tells-truth-design.md` carried two
   competing sets of "how long until a dead studio shows unreachable" numbers
   in the same section: an earlier round-2 estimate list (dead-from-deploy
   90s, killed ~101s, late-tick ~115s, worst case ~285s) sitting directly
   above the later, actually-measured table (dead plane 90/213 head vs
   117/243 main, killed 101/581 head vs 152/631 main, etc., worst case
   480s+~100s). The two disagreed — the table's own killed-scenario worst
   (581s main) contradicts the round-2 list's stated worst (~285s) — and the
   round-2 list's numbers were stale next to the table's real ones. Left both
   in place, a reader has no way to know which is current.

## The fix

Replaced the round-2 list's own restated numbers with a short paragraph
pointing forward to the measured table (which already carries the
`lastShipOkAt` re-anchoring fix layered on top), so there is exactly one set
of numbers, in one place. Adjusted the one cross-reference ("round 2's own
numbers above") that pointed at the now-removed list, and left the
surrounding round-1-caveat paragraph as-is since it does not depend on the
removed figures.

Also fixed `apps/fleet/src/studio/observed.ts`'s doc comment on
`isUnreachable`, which said "shared by the render-side gate above" — wrong,
since the render-side gate (`formatUnreachableLine`) lives in
`apps/fleet/cli/readiness-format.ts`, a different file. Now points at that
file directly.
