# #364 — shared chunked base64 encoder (deep-modules sweep 4, F4)

Goal: one UTF-8-safe chunked base64 encoder in a dependency-free shared module, replacing four hand-maintained copies. Behavior-preserving, two-way door.

## Copies being unified (paths relative to apps/fleet/)
- src/github/api.ts:197 — `base64EncodeUtf8(s)`, private, used by upsertRepoFile/createRepoFile (GitHub Contents API bodies)
- src/studio/blueprint.ts:346 — `base64EncodeUtf8(s)`, EXPORTED today; re-imported by studio-blueprint.ts, credentials.ts, test/studio.provision.test.ts
- src/studio/sandbox-api.ts:243 — `bytesToBase64(bytes)`, takes Uint8Array (no TextEncoder line)
- src/studio/gh-wrapper.ts:156 — `b64(s)`, one-line loop body (0x8000 inline)

## Design
- New src/base64.ts, imports NOTHING (tsconfig-reachability discipline github/mint-token-error.ts and github/reach.ts already document: a shared module that imported Env-typed files would drag the Worker type graph into the cli and bun-test tsconfig projects).
- Two exports: `bytesToBase64(bytes: Uint8Array): string` (the core loop, B64_CHUNK = 0x8000) and `base64EncodeUtf8(s: string): string` (TextEncoder then bytesToBase64).
- All four copies deleted; each file imports from src/base64. blueprint.ts STOPS exporting base64EncodeUtf8 — its 3 consumers import src/base64 directly. No pass-through re-export (repo culture, #357).
