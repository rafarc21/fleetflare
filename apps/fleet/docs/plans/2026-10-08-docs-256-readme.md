# Rewrite README to match claude-code-containers shape (board issue #256)

## Goal

Rewrite the root `README.md` to match the shorter, scannable shape and tone
of claude-code-containers' README (hero, features, quickstart, usage, dev,
license) instead of the current long, concept-heavy document.

## Approach

Condense `README.md` from 308 lines to ~172 lines matching that shape,
keeping every command verbatim from the original (no new facts, no
paraphrased commands). The sections that don't fit that shorter shape — Key
Concepts, How It Works, Safety, FAQ, Repository Layout — move to a new
`docs/architecture.md` rather than being dropped, and the README links out to
it so nothing from the original is silently lost. The safety section links
to the existing `docs/threat-model.md` instead of duplicating it.

## Review

Docs-only, light/bounded per board issue #256 and the maestro's own STATUS
brief for this task: maestro verifies directly, no separate code-review/QA
round.
