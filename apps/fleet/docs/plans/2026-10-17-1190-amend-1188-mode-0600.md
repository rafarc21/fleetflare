## 1. Keep 0600 through the atomic write

studio-bringup.sh's three settings-merge regions write the temp file with
`open(tmp, "w")` — umask 022 drops a prior 0600 settings.json to 0644 on
os.replace. Switch each to the glm-lead.ts:52-53 idiom:

    fd = os.open(tmp, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
    with os.fdopen(fd, "w") as f:
        json.dump(cfg, f, indent=2)
    os.replace(tmp, path)

Regions: lead-gate-settings-merge, activity-heartbeat-settings-merge,
completion-gate-settings-merge.
